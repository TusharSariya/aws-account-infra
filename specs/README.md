# Spec Kit features

Root-level numbered directories are the product and infrastructure intent authority.
Each feature follows `specs/NNN-feature-name/` and contains a specification, plan,
evidence-bearing tasks, research, data model, audit guide, and requirements checklists as
applicable. HTTP API descriptions live separately under `contracts/openapi/`.

PR #30 is documented in [`001-safe-service-vending/`](001-safe-service-vending/).
